## Install or update

```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/timmywheels/stoplight/main/install.sh)"
```

## What's new

- **The size you drag is the size you keep.** Resizing the panel no longer snaps back to fit the content. Auto-fit applies until you resize once; "Reset Panel Position and Size" in the dots' right-click menu hands it back.
- **Cleaner badges.** Conflicts, Merged, Queue and the rest now use neutral text with a small tinted glyph, instead of colored words competing with PR titles.
- **Top bar tidied.** Search and keyboard shortcuts on the left, expand-all and pin on the right, drag handle centered. The footer keeps the status filters and PR actions.
