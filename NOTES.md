Signed and notarized by Apple. The **Update** button in the popover footer does the rest.

## Install or update

```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/timmywheels/stoplight/main/install.sh)"
```

## What's new

- **Configurable row buttons.** Settings → General → Row buttons: check which circles an expanded PR shows, drag to reorder.
- **Copy commit hash.** New `#` button and ⇧⌘B copy the full SHA; the right-click menu shows the short hash.
